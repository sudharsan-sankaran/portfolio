# Sudharsan Sankaran — Portfolio

A personal portfolio for UK data opportunities, with the Atelier visual direction, an animated portrait composition and a searchable project journal.

## Run and build

Use Node.js 22 or later and pnpm. Install the locked dependencies with `pnpm install --frozen-lockfile`, then run `pnpm dev` or `pnpm build`.
The production website is exported to `out/`. No server, API key, browser extension or visitor account is required.

## Content

Edit `content/projects.json` to add projects. See [ADDING-PROJECTS.md](ADDING-PROJECTS.md) for the local form and automatic covers. Publish changes only after reviewing a fresh build.

The homepage is independent of project count. Case studies are generated at `/work/[slug]/`. Illustrative sculptures are conceptual, not measured project results. Reported aggregate model figures are explicitly labelled as not independently reproduced.

## Assets

The portrait is an edited/generated still approved by Sudharsan; the movement comes from page animation and separate procedural 3D geometry. It is not an animated human model. Original private footage, CV, academic reports, raw datasets and credentials are not included.
Font licence notices are retained in `public/legal/`. Dependencies retain their respective licences. No blanket licence is granted for personal portraits or third-party materials.
